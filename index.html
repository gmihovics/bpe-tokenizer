🔤 BPE Tokenizer Playground

Type some text and watch it get turned into tokens the same way modern language models do it — using Byte-Pair Encoding. Each stage of the pipeline explains what it's doing and shows the data at that exact moment. The BPE vocabulary is trained live on your input so you can actually watch merges happen.

Built as a learning tool. The tokenizer is plain, commented TypeScript in src/tokenizer.ts — read it to see exactly how BPE works. GPT and Claude all use this same byte-level BPE algorithm; what differs is the pre-tokenization regex (the schemes above, taken from OpenAI's open-source tiktoken) and a fixed vocabulary of ~100k merges trained once on huge corpora. Anthropic doesn't publish Claude's regex, so there's no faithful Claude preset here.
